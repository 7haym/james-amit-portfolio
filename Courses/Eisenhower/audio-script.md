# Narration files for "Beat the Busy Trap"

Create a folder named `audio` in the same place as `Eisenhower Micro Learning.html`, then save one file per screen using the exact names below.

```
Courses/
├── Eisenhower Micro Learning.html
└── audio/
    ├── 01.mp3
    ├── 02.mp3
    └── ... 11.mp3
```

Once the files are in place, set `SHOW_AUDIO_LABELS` to `false` near the top of the script in the HTML file to hide the file names from learners.

| File | Screen | Length | Narration |
|---|---|---|---|
| `audio/01.mp3` | 1. Welcome: Beat the Busy Trap | 30 sec | Have you ever ended a busy day feeling like you accomplished a lot, but your most important tasks are still unfinished? In this short course, you'll learn a simple way to decide what deserves your attention first. |
| `audio/02.mp3` | 2. Hook: Busy or Productive? | 45 sec | All these tasks may seem important when they compete for your attention. But should they all receive the same amount of time? The key is to decide which tasks need action now, which need planning, and which can wait or be removed. |
| `audio/03.mp3` | 3. Learning Objectives | 30 sec | By the end, you'll be able to use the Eisenhower Decision Matrix to sort tasks and choose a practical next step for your workload. |
| `audio/04.mp3` | 4. Meet the Matrix | 45 sec | Urgency is about timing and the consequences of delay. Importance is about impact. A task can be urgent, important, both, or neither. The matrix helps you decide what to do next. |
| `audio/05.mp3` | 5. The Four Quadrants | 60 sec | Do urgent, important tasks promptly. Schedule important tasks before they become urgent. Delegate or redirect urgent tasks when someone else is better placed to handle them. Eliminate or reduce activities that add little value. |
| `audio/06.mp3` | 6. See It in Action | 60 sec | The outage affects the customer and needs prompt attention. Both urgency and importance are high, so this task belongs in Quadrant 1. Now compare it with preparing for a project milestone due next month. That is important, but it can be planned in advance. |
| `audio/07.mp3` | 7. Practice: Where Does It Belong? | 75 sec | Try each task yourself. Look at its deadline, its impact, and whether you are the right person to handle it. Then choose the quadrant that best fits. |
| `audio/08.mp3` | 8. Apply It to Your Workload | 75 sec | You have several competing tasks. Start by checking the impact of each task and the consequence of waiting. Then decide which tasks need immediate action, planning, redirection, or removal. |
| `audio/09.mp3` | 9. Summary: Beat the Busy Trap | 30 sec | You do not need to treat every task as a top priority. Pause, assess urgency and importance, and choose your next action. Scheduling important work early can help prevent it from becoming another emergency. |
| `audio/10.mp3` | 10. Knowledge Check | 90 sec | Let's check your understanding. For each situation, choose the quadrant or action that best fits the information provided. |
| `audio/11.mp3` | 11. Closing: Your Next Move | 20 sec | Before you return to work, choose one task you need to handle. Use the matrix to decide whether to do it, schedule it, delegate it, or eliminate it. Small decisions can make your workload more manageable. |
